## Description

Ware turns EL wire, tape, and panels into lights you control from your phone.
Connect to your Ware controller over Bluetooth and command brightness, effects,
and multi-channel sequences in real time.

Whether it is a light-up jacket, a costume, a bike vest, or a retail display,
Ware gives you simple, expressive control over up to six independent channels.

FEATURES

- One-tap on and off with smooth dimming from a single glowing orb
- Built-in presets: Flame, Strobe, and Fade, each with an adjustable speed
- Per-channel patterns: solid, blink, fade pulse, SOS, turn signal, and sequence
- Group channels and run coordinated chase sequences across multiple panels
- Save and recall scenes, including ready-made presets like Bike Vest and SOS
- Patterns run on the controller itself, so your lights keep going even if your
  phone disconnects
- Demo Mode lets you explore the whole app with a simulated controller, no
  hardware needed

Gamma-corrected fades and on-device pattern playback keep every effect smooth
and reliable.

Ware requires a Ware EL light controller to control real lights. Without one,
use Demo Mode to try everything the app can do.

## App Review notes (paste into "Notes" for the reviewer)

Ware is a Bluetooth companion app for the Ware EL light controller hardware.
App Review cannot connect to the physical controller, so please use the built-in
Demo Mode to review all functionality: on first launch, tap "Explore in Demo

mode." This simulates a connected six-channel controller so every screen (the
